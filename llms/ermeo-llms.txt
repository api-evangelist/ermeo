# Ermeo

> Ermeo (rebranded Causeway Field) is a French connected-operator / field-operations SaaS platform that digitizes paper procedures into dynamic, interactive workflows for inspections, maintenance, and interventions. Operators complete pre-built forms on mobile and capture equipment and report data in the field in real time; managers monitor field work from a central console. Ermeo exposes a REST API secured with OAuth 2.0 so customers can connect their information systems (CMMS, MES, EDM) to import and synchronize equipment, forms, and reports.

## API

- [Ermeo API reference (Stoplight)](https://ermeo.stoplight.io/): REST API, OAuth 2.0 Bearer auth, base URL https://api.ermeo.com
- [Authenticate and send requests](https://support.en.ermeo.com/login-to-ermeo-api-and-send-requests): OAuth 2.0 password + refresh_token grants, token endpoint https://api.ermeo.com/oauth/v2/token
